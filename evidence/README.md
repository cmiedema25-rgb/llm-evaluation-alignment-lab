# Retained Evidence

- `benchmark-report.json` is generated by the public CLI and contains the exact
  aggregate and per-case evaluation results.
- `VERIFICATION.md` records the clean-environment lint, test, coverage, and
  benchmark results for this revision.

Regenerate the report:

~~~bash
llm-eval-lab benchmark data/evaluation_cases.jsonl \
  --preferences data/sample_preferences.jsonl \
  --report evidence/benchmark-report.json
~~~

The checked-in cases and annotations are authored examples. This report is a
regression baseline, not an independent evaluation of a hosted language model.
